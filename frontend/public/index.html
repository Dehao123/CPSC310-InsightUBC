Section Insights Dashboard

Backend service runs on http://localhost:4321 by default. Use the cards below to: add / view / remove datasets, and run common query templates.

1. Add Dataset sections.zip → addDataset

Upload a .zip file containing UBC sections and assign it a dataset id (e.g., sections). This id will be used as a query prefix later.

No file chosen

2. List Datasets listDatasets

View all datasets currently on the server, including each dataset's type and row count.

3. Remove Dataset removeDataset

Enter the dataset id to remove. You can usually confirm the name in "List Datasets" first, then proceed with removal.

4. Section Insights Queries performQuery

Queries are divided into two types: Simple Query for common queries, such as finding courses with the highest average grades in a department; Advanced Query can add conditions for enrollment and grades.

Simple Query: First select which field to filter by (e.g., dept / id / instructor / year), then enter the corresponding value. Results will be sorted by course average from high to low, showing only the top N rows.

Advanced Query: In a specified department, find sections where pass count (pass) is greater than a certain value, and average grade is greater than a certain value.
