Section Insights Dashboard

后端服务默认运行在 http://localhost:4321。 使用下面的卡片可以：添加 / 查看 / 删除数据集，以及运行几个常用的查询模板。

1. Add Dataset sections.zip → addDataset

上传包含 UBC sections 的 .zip 文件，并为它指定一个 dataset id （例如 sections）。这个 id 之后会作为查询前缀使用。

2. List Datasets listDatasets

查看当前服务器中有哪些 datasets，以及每个 dataset 的类型和行数。

3. Remove Dataset removeDataset

输入要删除的 dataset id。通常可以先在「List Datasets」里确认名称，再执行删除。

4. Section Insights Queries performQuery

这里把查询分成两类：Simple Query 用来做非常常见的查询， 比如某个院系里哪些课程平均分最高；Advanced Query 可以加上人数和分数的条件。

Simple Query：先选择你想根据哪个字段过滤（如 dept / id / instructor / year）， 再输入对应的值。结果仍然会按课程平均分从高到低排序，并只显示前 N 行。
